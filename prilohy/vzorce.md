# Vzorce

## Čísla
→ [kapitola](../zaklady/01-cisla/vyklad.md)

| vzorec | význam |
|---|---|
| $\mathbb{N} = \{1, 2, 3, \dots\}$, $\ \mathbb{Z} = \{\dots, -1, 0, 1, \dots\}$ | přirozená a celá čísla |
| $\lvert a \rvert \ge 0$ | absolutní hodnota není záporná |
| $a - b = a + (-b)$ | odčítání je přičítání opačného čísla |
| $(-a) \cdot (-b) = a \cdot b$ | stejná znaménka → kladný výsledek |
| $(-a) \cdot b = -(a \cdot b)$ | různá znaménka → záporný výsledek |
| závorky → $\cdot$ a $:$ → $+$ a $-$ | pořadí početních operací |

## Zlomky
→ [kapitola](../zaklady/02-zlomky/vyklad.md)

| vzorec | význam |
|---|---|
| $\frac{a}{b} = a : b$, $\ b \ne 0$ | zlomek je dělení |
| $\frac{a}{b} = \frac{a \cdot k}{b \cdot k}$, $\ k \ne 0$ | rozšiřování a krácení |
| $\frac{a}{c} + \frac{b}{c} = \frac{a + b}{c}$ | sčítání se stejným jmenovatelem |
| $\frac{a}{b} \cdot \frac{c}{d} = \frac{a \cdot c}{b \cdot d}$ | násobení |
| $\frac{a}{b} : \frac{c}{d} = \frac{a}{b} \cdot \frac{d}{c}$ | dělení |
| $-\frac{a}{b} = \frac{-a}{b} = \frac{a}{-b}$ | záporný zlomek |

## Mocniny
→ [kapitola](../zaklady/03-mocniny/vyklad.md)

| vzorec | význam |
|---|---|
| $a^n = a \cdot a \cdot \ldots \cdot a$ ($n$ činitelů) | definice mocniny |
| $a^m \cdot a^n = a^{m+n}$ | násobení mocnin se stejným základem |
| $a^m : a^n = a^{m-n}$, $\ a \ne 0$ | dělení mocnin se stejným základem |
| $(a^m)^n = a^{m \cdot n}$ | mocnina mocniny |
| $(a \cdot b)^n = a^n \cdot b^n$, $\ \left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}$ | mocnina součinu a podílu |
| $a^0 = 1$, $\ a^{-n} = \frac{1}{a^n}$, $\ a \ne 0$ | nultá a záporná mocnina |
| $a \cdot 10^n$, $\ 1 \le a < 10$ | zápis velkých a malých čísel |

## Odmocniny
→ [kapitola](../zaklady/04-odmocniny/vyklad.md)

| vzorec | význam |
|---|---|
| $\sqrt{a} = b \iff b^2 = a,\ b \ge 0$ | definice druhé odmocniny ($a \ge 0$) |
| $\left(\sqrt{a}\right)^2 = a$, $\ \sqrt{a^2} = \lvert a \rvert$ | odmocnina a mocnina se ruší |
| $\sqrt{a \cdot b} = \sqrt{a} \cdot \sqrt{b}$ | odmocnina součinu |
| $\sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}$, $\ b > 0$ | odmocnina podílu |
| $\frac{1}{\sqrt{a}} = \frac{\sqrt{a}}{a}$ | usměrnění zlomku |
| $a^{\frac{1}{n}} = \sqrt[n]{a}$, $\ a^{\frac{m}{n}} = \sqrt[n]{a^m}$ | odmocnina jako mocnina |
| $\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$ | číselné obory |

## Teorie množin
→ kapitoly [01](../teorie-mnozin/01-mnozina-a-jeji-zapis/vyklad.md) · [02](../teorie-mnozin/02-vztahy-mezi-mnozinami/vyklad.md) · [03](../teorie-mnozin/03-operace-s-mnozinami/vyklad.md) · [04](../teorie-mnozin/04-intervaly/vyklad.md) · [05](../teorie-mnozin/05-kartezsky-soucin-a-mohutnost/vyklad.md)

| vzorec | význam |
|---|---|
| $B \subset A$ | každý prvek $B$ je prvkem $A$ |
| $A = B \iff A \subset B$ a $B \subset A$ | rovnost množin |
| množina s $n$ prvky má $2^n$ podmnožin | počet podmnožin |
| $A \cup B$, $\ A \cap B$, $\ A \setminus B$, $\ A' = Z \setminus A$ | sjednocení, průnik, rozdíl, doplněk |
| $(A \cup B)' = A' \cap B'$, $\ (A \cap B)' = A' \cup B'$ | De Morganovy zákony |
| $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ | distributivní zákon |
| $\lvert A \cup B \rvert = \lvert A \rvert + \lvert B \rvert - \lvert A \cap B \rvert$ | počet prvků sjednocení |
| $\langle a, b \rangle$: $a \le x \le b$; $\ (a, b)$: $a < x < b$ | uzavřený a otevřený interval |
| $\lvert A \times B \rvert = \lvert A \rvert \cdot \lvert B \rvert$ | počet prvků kartézského součinu |
