# Intervaly – příklady

K výkladu: [Intervaly](vyklad.md)

1. Zapište intervalem: [→ řešení](reseni.md#úloha-1)
   - a) $\{x \in \mathbb{R} ;\ 1 \le x \le 5\}$
   - b) $\{x \in \mathbb{R} ;\ -2 < x < 0\}$
   - c) $\{x \in \mathbb{R} ;\ 3 \le x < 8\}$
   - d) $\{x \in \mathbb{R} ;\ -4 < x \le -1\}$

2. Zapište intervalem: [→ řešení](reseni.md#úloha-2)
   - a) $x \ge 3$
   - b) $x < -1$
   - c) $x > 0$
   - d) $x \le \frac{1}{2}$

3. Zapište nerovností a rozhodněte, zda číslo $2$ do intervalu patří: [→ řešení](reseni.md#úloha-3)
   - a) $\langle 2, 7)$
   - b) $(-1, 2)$
   - c) $(-\infty, 2\rangle$
   - d) $(1{,}9;\ 2{,}1)$

4. Najděte chyby v zápisech: [→ řešení](reseni.md#úloha-4)
   - a) $\langle 5, \infty \rangle$
   - b) $(4, 1)$
   - c) $\langle -\infty, 0)$

5. Vypište všechna celá čísla, která leží v intervalu: [→ řešení](reseni.md#úloha-5)
   - a) $\langle -2, 3)$
   - b) $(0, 1)$
   - c) $(-3{,}5;\ 1 \rangle$

6. Určete průnik a sjednocení intervalů: [→ řešení](reseni.md#úloha-6)
   - a) $A = \langle -1, 3 \rangle$, $B = (1, 5)$
   - b) $A = (-\infty, 2)$, $B = \langle 0, \infty)$
   - c) $A = \langle 1, 2 \rangle$, $B = (3, 4)$
   - d) $A = (0, 4)$, $B = \langle 1, 2 \rangle$

7. Určete $A \setminus B$ a $B \setminus A$ pro $A = \langle 0, 5 \rangle$ a $B = (2, 8)$. [→ řešení](reseni.md#úloha-7)

8. Určete doplněk v $\mathbb{R}$: [→ řešení](reseni.md#úloha-8)
   - a) $\langle 1, 4 \rangle$
   - b) $(-\infty, 3)$
   - c) $(-2, 0\rangle$

9. ⭐ Určete $A \cap B \cap C$ pro $A = (-\infty, 5)$, $B = \langle -3, 10)$ a $C = (1, \infty)$. [→ řešení](reseni.md#úloha-9)

10. ⭐ Určete průnik intervalů $\langle 2, 6)$ a $\langle 6, 9 \rangle$. Jak se výsledek změní, když první interval bude $\langle 2, 6\rangle$? [→ řešení](reseni.md#úloha-10)

11. ⭐⭐ Zapište množinu $\{x \in \mathbb{R} ;\ |x| < 3\}$ a množinu $\{x \in \mathbb{R} ;\ |x| \ge 3\}$ pomocí intervalů. Nápověda: $|x|$ je vzdálenost čísla $x$ od nuly. [→ řešení](reseni.md#úloha-11)
